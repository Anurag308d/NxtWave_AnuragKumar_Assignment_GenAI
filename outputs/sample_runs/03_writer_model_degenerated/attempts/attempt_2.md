# Introduction to Retrieval-Augmented Generation (RAG)

## What Is RAG?

RAG is a method for making **Large** **Model** (LLM) **answers** **better**. It has two main parts. First, it **retr** **ies** **relevant** **information**. Then, it **gener** **ates** **a** **response**.

Think of a **medical** **student**. In a **closed-book** **exam**, they rely on **memory**. They might **forget** **facts**. They might **guess**.

In an **open-book** **exam**, they **search** **the** **textbook**. They **find** **the** **right** **page**. Then they **write** **the** **correct** **response**.

RAG is like that **open-book** **exam**. It **finds** **facts** **first**. Then it **writes** **the** **response**.

## What Is RAG?

RAG is a method for making **Large** **Model** (LLM) **answers** **better**. It has two main **parts**.

**Retri** **val** **means** **finding**. The system **loc** **ates** **relevant** **text**. It **searches** **a** **data** **source**.

**Aug** **mented** **means** **improved**. The system **adds** **the** **text** **to** **the** **prompt**. It **gives** **the** **model** **context**.

**Gene** **ration** **means** **creating**. The LLM **writes** **the** **final** **text**. It **uses** **the** **provided** **facts**.

So, RAG **finds** **information**. Then it **uses** **it** **to** **write**. This is **different** **from** **pure** **memory**.
